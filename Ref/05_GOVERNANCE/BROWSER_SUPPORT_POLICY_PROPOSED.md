# Browser Support Policy — Proposed Phase-0 Baseline

Support managed modern enterprise browsers:

- Microsoft Edge: current + previous stable
- Google Chrome: current + previous stable
- Firefox: current + previous stable where customer policy allows
- Safari: current + previous stable for supported Apple usage

No Internet Explorer support.

On-premise deployment does not imply legacy-browser compatibility.

Any customer contract requiring an older browser creates an explicit compatibility ADR and must be tested before commitment.
