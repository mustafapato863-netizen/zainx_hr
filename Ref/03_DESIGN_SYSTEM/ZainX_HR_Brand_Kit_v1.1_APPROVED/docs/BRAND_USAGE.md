# Zain X HR — Approved Brand Usage

## Source of truth
The approved brand board in `source/approved-brand-board.png` is the visual source of truth.

This kit intentionally uses exact extracted artwork from that board so the in-app brand matches the approved concept:
- Blue → cyan ZX mark
- Human figure inside the ZX negative-space/intersection
- Human-shaped `i` in the Zain wordmark
- `Zain X HR`
- `HUMAN RESOURCES PLATFORM`
- Primary Navy `#0A1330`
- Zain Blue `#2563FF`
- Zain Cyan `#00D4FF`

## App usage
- Expanded shell/header: `logos/zainx-hr-primary-lockup.webp`
- Collapsed sidebar: `logos/zainx-hr-mark.webp`
- Login/intro: mark + controlled text reveal
- Browser/PWA: `pwa/`
- Landing/welcome: primary lockup
- Monochrome usage: use PNG variants or CSS mask with the exact approved mark

## Important production note
The approved source provided is a raster brand board, not an original vector master.
Therefore this kit prioritizes exact visual fidelity over pretending to provide a native vector reconstruction.
For print-scale fabrication or trademark master files, recreate the approved geometry in Figma/Illustrator and export native SVG/PDF/EPS without changing its silhouette.
