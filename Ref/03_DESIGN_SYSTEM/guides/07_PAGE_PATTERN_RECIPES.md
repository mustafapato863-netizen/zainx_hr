# Page Pattern Recipes

## P1 Operational Dashboard

Use for:
Home, Payroll Overview, Time Overview, Recruitment Dashboard.

Recipe:
1. PageHeader
2. Critical blocker/banner if needed
3. 3–6 KPIs
4. Work requiring action
5. diagnostic trend
6. recent/upcoming activity

Reject:
12-card KPI grids with no action.

---

## P2 Data Grid / List

Use for:
Employees, Payroll Runs, Candidates, Requests, Documents.

Recipe:
1. PageHeader
2. PageToolbar
3. View selector
4. FilterBar
5. DataGrid
6. BulkActionBar when selected
7. Pagination
8. QuickPreview Drawer

---

## P3 Detail Workspace

Use for:
Employee, Candidate, Requisition, Legal Entity.

Recipe:
1. Breadcrumb
2. EntityHeader
3. Status + primary actions
4. Tabs
5. Main detail
6. optional contextual drawer
7. timeline/audit

---

## P4 Guided Process

Use for:
Payroll, onboarding, offboarding, imports.

Recipe:
1. ProcessHeader
2. Stepper
3. blockers/readiness
4. active step
5. contextual help
6. previous/next or state-based primary action
7. save/resume
8. final confirmation

---

## P5 Kanban / Pipeline

Use for:
Recruitment Pipeline.

Recipe:
1. Job/context header
2. FilterBar
3. Pipeline columns
4. Candidate cards
5. quick preview
6. accessible Move action
7. optional collaboration/evaluation state

---

## P6 Calendar / Schedule

Use for:
Leave, shifts, interviews.

Recipe:
1. context/date controls
2. view switcher
3. filters
4. calendar
5. list/agenda alternative
6. quick detail

---

## P7 Inbox / Exceptions

Use for:
My Work, Attendance Exceptions, Payroll Exceptions, AI Learning.

Recipe:
1. count/priority summary
2. filter/view controls
3. work list
4. age/owner/reason
5. preview
6. action
7. safe bulk resolution

---

## P8 Configuration / Builder

Use for:
Policies, payroll components, pipeline stages, mappings.

Recipe:
1. SettingsHeader
2. configuration navigation
3. form/builder
4. effective date/version
5. impact warning
6. draft/publish state
7. audit metadata
8. save/publish action
